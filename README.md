# AI×PI 数据分析 SKILL

> **通用数据分析技能包** — 从数据上传到行动决策，一套完整的 AI 辅助分析流程。
>
> 适用于：经营分析、销售诊断、用户研究、运营复盘、绩效改进等任何结构化数据分析场景。

---

## 快速开始

### 方式一：轻量版（5 分钟上手）

1. 打开 [`prompt/quick-prompt.md`](prompt/quick-prompt.md)
2. 复制全部内容
3. 粘贴到 **Kimi / 豆包 / 智谱清言** 等支持代码执行的 AI 中
4. 上传你的 Excel/CSV 数据
5. 等待 AI 输出分析结论

### 方式二：完整版（系统学习）

1. 阅读 [`skill/data-analysis-skill.md`](skill/data-analysis-skill.md) — 理解完整方法论
2. 参考 [`guide/student-guide.md`](guide/student-guide.md) — 掌握使用技巧和常见问题
3. 查看 [`examples/`](examples/) — 参考完整分析示例

## 核心特点

| 特点 | 说明 |
|---|---|
| **通用性强** | 不绑定任何行业，餐饮、零售、制造、互联网均可使用 |
| **数据精准** | 基于 Python 脚本执行，统计结果 100% 准确（非估算） |
| **环境自适应** | 自动检测 AI 是否支持代码执行，不支持时提示切换环境 |
| **双模式输出** | 先出「核心发现草稿」供讨论，再出「四栏正式报告」供提交 |
| **模板沉淀** | 每次分析自动提炼「可复用模板」，实现知识积累 |
| **方法论有据** | 所有分析原则均标注 APA 7.0 格式来源 |

## 核心方法论

本 SKILL 遵循以下分析哲学：

1. **对比产生意义** — 没有对比的数字是死数字
2. **异常值是金矿** — 偏离均值的数据点往往最有价值
3. **标题就是结论** — 不写"数据分析"，写"苏州区域连续三月下滑，需预警"
4. **假设必须标"假设："** — 是假设就说是假设，不许写成定论
5. **动作必须到人到期** — 没有责任人和 deadline 的动作等于没写

## 使用场景

- 📊 **季度经营复盘**：基于门店/区域/渠道数据，找出问题与机会
- 📈 **销售诊断**：分析销售额、客单价、转化率等指标，定位瓶颈
- 👥 **用户分析**：基于用户行为数据，识别高价值用户与流失风险
- 🏭 **生产运营**：分析产能、良率、损耗等指标，优化运营效率
- 🎯 **绩效改进**：基于 KPI 数据，找出绩效差距与改进路径
