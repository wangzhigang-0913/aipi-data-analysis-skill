# 数据分析 SKILL（通用版）

> **版本**: v1.0  
> **适用场景**: 任何需要基于结构化数据（Excel/CSV）进行经营分析、业务诊断、问题挖掘的场景  
> **核心理念**: 对比产生意义，异常值是金矿，假设必须标"假设："，动作必须到人到期  
> **设计来源**: AI×PI课程「积累打法（Codify）」模块

---

## 一、使用声明

### 1.1 本 SKILL 解决什么问题

当你拿到一份业务数据（门店经营、销售报表、用户行为、生产数据等），需要快速完成以下工作时，使用本 SKILL：

1. **理解数据结构**：这份数据在说什么？
2. **发现核心问题**：哪些数字在报警？哪些在报喜？
3. **形成分析结论**：不是罗列数字，而是回答 "So What？"
4. **输出行动方案**：从数据到决策，从决策到行动。

### 1.2 本 SKILL 不解决什么问题

- ❌ 不替代统计学专业知识（如需回归分析、假设检验，请咨询数据科学家）
- ❌ 不处理非结构化数据（如文本、图片、音频）
- ❌ 不做预测（本 SKILL 聚焦 "发生了什么"，而非 "将要发生什么"）

### 1.3 使用前提

- 数据格式：Excel（.xlsx / .xls）或 CSV（.csv）
- 数据规模：建议单次分析不超过 5,000 行 × 30 列（超出请分批次）
- 时间要求：从上传数据到输出结构1，约 5–10 分钟；到输出结构2，约 15–20 分钟

## 三、数据质量四问（5 分钟）

**在分析之前，必须先回答以下四个问题。** 如果答案为"否"或"不确定"，分析结论的可信度将大幅下降。

### 3.1 行数是否与预期一致？

- **问自己**：根据业务常识，这份数据应该有多少行？
- **示例**：32 家门店 × 3 个月 = 96 条记录，实际 84 条 → 缺失 12 条，需追问原因
- **行动**：记录 "数据覆盖缺口"，在最终报告中标注

### 3.2 关键指标是否有缺失值？

- **问自己**：哪些列存在空值？空值比例是多少？空值是否有规律？
- **示例**：外卖占比缺失 1 处（堂食店，逻辑上可接受）；满意度缺失 2 处（无法判断达标情况）
- **行动**：缺失值 >5% 的列，分析时需谨慎引用；缺失值需标注为"数据缺失"

### 3.3 是否有明显超出业务常识的异常值？

- **问自己**：是否存在负数、超过 100% 的占比、超过满分上限的评分？
- **示例**：满意度 5 分制，出现 6 分 → 数据错误；外卖占比 95% → 需确认是否为纯外卖站
- **行动**：标记异常值，在报告中单独列出，但不直接删除

### 3.4 时间范围是否完整？

- **问自己**：数据覆盖的时间段是否与分析目标一致？是否有断档？
- **示例**：Q2 数据应覆盖 4–6 月，实际 4–6 月完整 → 通过；若只有 4–5 月 → 需标注 "6 月数据缺失"
- **行动**：时间断档直接影响趋势分析结论，必须在报告中声明

**自检完成后，输出一段「数据可信度评估」：**

> 示例："本数据共 84 条记录，覆盖 28 家门店（目标 32 家，缺失 4 家）。关键指标中，外卖占比缺失 1 处（1.2%），满意度缺失 2 处（2.4%），均在可接受范围。未发现超出业务常识的异常值。时间范围 4–6 月完整。整体数据可信度：中高。"

## 四、分析流程（三阶段）

### 阶段一：理解结构（3 分钟）

**目标**：搞清楚这份数据在说什么，不要盲目计算。

**必须回答的问题：**

1. **一行代表什么？**（一条投放记录？一个用户？一家门店一个月？）
2. **哪些列是维度？**（用来分组的类别列，如 "城市""业态""渠道"）
3. **哪些列是指标？**（用来计算的数值列，如 "营业额""客流量""满意度"）
4. **有没有时间列？** 数据覆盖什么时间范围？
5. **指标的计算口径是什么？**（如 "营业额" 是含税还是不含税？"客流量" 是到店人次还是订单数？）

**输出格式：**

```
数据理解摘要
- 数据粒度：每行 = [X]
- 维度列：[列名列表]
- 指标列：[列名列表]
- 时间范围：[起止时间]
- 关键口径说明：[如有]
```

---

### 阶段二：统计概况（5 分钟）

**目标**：对每个指标列，快速画出"数字画像"。

#### 2.1 单指标统计（每个指标列执行）

| 统计量 | 说明 | 判断规则 |
|---|---|---|
| **均值** | 平均值 | 与中位数对比 |
| **中位数** | 排在 50% 位置的值 | 若均值与中位数差距 >20%，说明分布偏斜，**中位数更可靠** |
| **P25 / P75** | 25% 和 75% 分位 | 了解数据集中区间 |
| **P95** | 95% 分位 | 了解极端高值边界 |
| **最小值 / 最大值** | 边界值 | 检查是否有异常 |
| **零值数量** | 值为 0 的个数 | 零值过多可能意味着数据缺失被填为 0 |
| **缺失值数量** | 空值个数 | 缺失比例 >5% 需警惕 |

#### 2.2 分组对比（按维度列分组）

**对每个维度列，计算各组的指标均值/中位数，找出差异最大的组。**

**输出格式：**

```
【按 [维度] 分组对比】
- [组A]：均值=X，中位数=Y，样本量=Z
- [组B]：均值=X，中位数=Y，样本量=Z
- 差异最大：[组A] 的 [指标] 比 [组B] 高/低 [百分比]
```

---

### 阶段三：挖掘发现（7 分钟）

**目标**：从统计数字中提炼业务洞察。遵循 "对比产生意义，异常值是金矿"。

#### 3.1 异常检测

**方法**：找出偏离组内均值 2 个标准差以上的记录。

**执行步骤：**
1. 选择一个维度（如 "业态" 或 "城市"）
2. 对每个组，计算某指标的均值和标准差
3. 找出超出 [均值 ± 2×标准差] 范围的记录
4. 标注："该记录偏离 [组] 的 [指标] 均值 [X] 个标准差"

**注意**：异常值 ≠ 错误值。异常值是 "值得深挖的金矿"，可能是问题，也可能是机会。

#### 3.2 相关性分析

**方法**：计算指标间的皮尔逊相关系数（Pearson r）。

**判断规则：**

| \|r\| 范围 | 相关强度 | 业务含义 |
|---|---|---|
| 0.00 – 0.30 | 弱相关 | 基本无关 |
| 0.30 – 0.70 | 中等相关 | 有关联，但非决定性 |
| **0.70 – 1.00** | **强相关** | **高度关联，需重点关注** |

**输出格式：**

```
【强相关指标对 (|r| > 0.7)】
- [指标A] × [指标B]：r = [值]，方向=[正/负]
  → 业务解读：[例如：客单价与外卖占比强负相关，说明外卖模式天然拉低客单]
```

#### 3.3 趋势分析（如有时间列）

**方法**：按时间维度汇总指标，观察变化方向。

**输出格式：**

```
【[指标] 月度趋势】
- [时间1]：均值=X
- [时间2]：均值=Y（环比 [+/-百分比]%）
- [时间3]：均值=Z（环比 [+/-百分比]%）
- 趋势判断：[上升/下降/平稳/波动]
```

#### 3.4 主动追问：隐藏问题挖掘

**分析完成后，必须追问以下问题，并在报告中回答：**

1. **"还有什么用户可能没意识到，但数据已经暗示的趋势或风险？"**
2. **"哪些指标之间存在矛盾？"**（如：营收增长但满意度下降）
3. **"如果我是这个业务的负责人，我最应该担心的三件事是什么？"**

## 六、输出结构2：四栏正式报告

**目标**：将核心发现整理为可提交、可汇报、可追踪的正式报告。

### 四栏结构

| 栏位 | 要求 | 红线 |
|---|---|---|
| **现场事实** | 只写看到的、量到的，不写判断。每个事实带一个数字。 | 没有数字支撑的事实，不许进报告。 |
| **与基准对比** | 必须给出对比基准数字。基准可选：上期/去年同期/目标值/组内均值。拿不到就写「数据缺失」，不许估。 | 拿不到的数据，写「缺失」，不许编。 |
| **根因假设** | 每条必须以「假设：」开头。是假设就说是假设，不许写成定论。 | 假设不许伪装成结论。 |
| **管理决策/改进动作** | 每条到人、到期、可检查。例如："张三，7月15日前，把高峰等位压到20分钟内"。 | 动作模糊、无责任人、无 deadline，不许进报告。 |

### 输出格式

```markdown
## 四栏经营分析报告

### 条目1
| 现场事实 | 与基准对比 | 根因假设 | 管理决策/改进动作 |
|---|---|---|---|
| [事实描述，带数字] | [对比基准及数字，或"数据缺失"] | 假设：[假设描述] | [责任人，deadline，可检查标准] |

### 条目2
| 现场事实 | 与基准对比 | 根因假设 | 管理决策/改进动作 |
|---|---|---|---|
| ... | ... | ... | ... |
```

### 格式规范

1. **全文不超过 10 页**（A4，单倍行距）
2. **先说结论，再摆事实**：报告开头用 1–2 句话概括核心结论
3. **每栏必须有数字**：即使是 "根因假设"，也要引用支撑假设的数据
4. **假设必须可证伪**：好的假设应该可以通过补充数据或实验来验证/推翻

## 九、Python 脚本模板（脚本模式专用）

**以下脚本为通用模板，可根据实际数据结构调整列名后运行。**

### 9.1 数据读取与清洗

```python
import pandas as pd
import numpy as np

# 读取数据
# Excel: df = pd.read_excel('文件名.xlsx', sheet_name='工作表名')
# CSV:  df = pd.read_csv('文件名.csv', encoding='utf-8')

# 基础信息
print(f"数据形状: {df.shape}")
print(f"列名: {list(df.columns)}")
print(f"
数据类型:
{df.dtypes}")
print(f"
缺失值:
{df.isnull().sum()}")
print(f"
前5行:
{df.head()}")

# 数值列统计
desc = df.describe()
print(desc)
```

### 9.2 统计概况（均值、中位数、分位数）

```python
numeric_cols = df.select_dtypes(include=[np.number]).columns.tolist()

for col in numeric_cols:
    data = df[col].dropna()
    mean_v = data.mean()
    median_v = data.median()
    gap_pct = abs(mean_v - median_v) / median_v * 100 if median_v != 0 else 0
    skew_flag = "分布偏斜" if gap_pct > 20 else "分布相对对称"

    print(f"【{col}】")
    print(f"  均值={mean_v:.2f}, 中位数={median_v:.2f}, 差距={gap_pct:.1f}% → {skew_flag}")
    print(f"  P25={data.quantile(0.25):.2f}, P75={data.quantile(0.75):.2f}, P95={data.quantile(0.95):.2f}")
    print(f"  最小={data.min():.2f}, 最大={data.max():.2f}, 缺失={df[col].isnull().sum()}")
```

### 9.3 分组对比

```python
# 按维度分组（将 '维度列名' 替换为实际列名）
dimension = '维度列名'  # 例如: '城市', '业态', '渠道'
for col in numeric_cols:
    print(f"
【按 {dimension} 分组的 {col}】")
    grouped = df.groupby(dimension)[col].agg(['mean', 'median', 'count', 'std'])
    print(grouped.round(2))
```

### 9.4 异常检测（偏离组内均值 2σ）

```python
dimension = '维度列名'
target_col = '指标列名'

for group in df[dimension].unique():
    subset = df[df[dimension] == group][target_col].dropna()
    if len(subset) <= 2:
        continue
    mean_v = subset.mean()
    std_v = subset.std()
    lower = mean_v - 2 * std_v
    upper = mean_v + 2 * std_v
    outliers = df[(df[dimension] == group) & ((df[target_col] < lower) | (df[target_col] > upper))]
    if len(outliers) > 0:
        print(f"
[{group}] {target_col} 均值={mean_v:.2f}, 2σ范围=[{lower:.2f}, {upper:.2f}]")
        for _, row in outliers.iterrows():
            print(f"  → 异常记录: {target_col}={row[target_col]}")
```

### 9.5 相关性分析

```python
corr_matrix = df[numeric_cols].corr()
print("【相关性矩阵】")
print(corr_matrix.round(3))

print("
【强相关对 (|r| > 0.7)】")
for i in range(len(numeric_cols)):
    for j in range(i+1, len(numeric_cols)):
        r = corr_matrix.iloc[i, j]
        if abs(r) > 0.7:
            direction = "正相关" if r > 0 else "负相关"
            print(f"  {numeric_cols[i]} × {numeric_cols[j]}: r={r:.3f} ({direction})")
```

### 9.6 趋势分析（时间序列）

```python
# 将 '时间列名' 替换为实际列名
time_col = '时间列名'
df[time_col] = pd.to_datetime(df[time_col])  # 确保为日期格式

monthly = df.groupby(time_col)[numeric_cols].mean()
print("【月度趋势】")
print(monthly.round(2))

# 环比变化
print("
【环比变化】")
for col in numeric_cols:
    changes = monthly[col].pct_change() * 100
    print(f"  {col}: {changes.round(1).to_dict()}")
```

## 十、方法论来源（APA 7.0 格式）

本 SKILL 的分析方法论基于以下学术与行业实践来源：

1. **Tufte, E. R.** (2001). *The visual display of quantitative information* (2nd ed.). Graphics Press.  
   → 核心理念："对比产生意义"源自 Tufte 的数据可视化与信息设计原则。

2. **Shewhart, W. A.** (1931). *Economic control of quality of manufactured product*. Van Nostrand.

   → 小组讨论与根因假设环节参考行动学习法（Action Learning），强调在质疑与反思中逼近真相。
